# Gestão Digital de Processos Administrativos e Logísticos

Projeto acadêmico desenvolvido para a disciplina **Atividade Extensionista II: Tecnologia Aplicada à Inclusão Digital – Projeto**, do curso de **Gestão da Tecnologia da Informação** do Centro Universitário Internacional UNINTER.

## Sobre o projeto

O projeto apresenta uma proposta de solução digital para organizar e acompanhar processos administrativos e logísticos de uma indústria de móveis localizada em Boituva – SP.

A solução foi desenvolvida utilizando uma base de dados fictícia no Microsoft Excel e painéis interativos no Microsoft Power BI.

> **Observação:** devido ao encerramento do vínculo de trabalho com a empresa durante a execução final da atividade, foram utilizados dados fictícios, sem informações reais ou confidenciais. Os resultados representam a execução e a validação funcional de um protótipo, não uma implantação real na organização, conforme solicitado a tutoria anteriormente e informado.

## Objetivos

1. Analisar os processos administrativos e logísticos, identificando oportunidades de melhoria na organização e no acompanhamento das informações.
2. Desenvolver uma solução digital utilizando Microsoft Excel, com uma base de dados fictícia e controles automatizados.
3. Implementar um painel no Microsoft Power BI para consolidar e visualizar indicadores que auxiliem no acompanhamento e na tomada de decisões.

## Tecnologias utilizadas

- Microsoft Excel;
- Microsoft Power BI;
- Power Query;
- Linguagem DAX;
- GitHub para documentação e disponibilização das evidências.

## Base de dados

A base fictícia utilizada no projeto contém:

- 120 pedidos;
- 30 clientes cadastrados;
- 28 clientes com pedidos;
- 20 produtos;
- Informações de estoque;
- Datas previstas e realizadas de entrega;
- Valores brutos, líquidos, custos, fretes e margens;
- Situação dos pedidos e dos prazos.

## Painéis desenvolvidos

### 1. Visão Geral

A página de visão geral apresenta os principais indicadores administrativos, financeiros e logísticos:

- Total de pedidos;
- Valor líquido;
- Pedidos entregues;
- Pedidos atrasados;
- Taxa de entregas no prazo;
- Margem estimada;
- Pedidos por status;
- Situação dos prazos;
- Valor líquido por categoria;
- Pedidos por mês.

## Resultados obtidos

Os painéis apresentaram os seguintes resultados:

- 120 pedidos analisados;
- 87 pedidos entregues;
- 38 pedidos entregues no prazo;
- 49 pedidos entregues com atraso;
- 26 pedidos ainda atrasados;
- 7 pedidos cancelados;
- Taxa de entrega no prazo de 43,7%;
- Valor líquido total de R$ 361.319,02;
- Margem estimada de R$ 87.835,30;
- Estoque atual total de 563 unidades;
- Estoque mínimo total de 322 unidades;
- Nenhum produto abaixo do estoque mínimo;
- 28 clientes com pedidos distribuídos entre nove cidades.

1. Baixe a base fictícia em formato `.xlsx`.
2. Baixe o arquivo do painel em formato `.pbix`.
3. Abra o arquivo `.pbix` utilizando o Microsoft Power BI Desktop.
4. Caso seja solicitado, atualize o caminho da fonte de dados para indicar o local onde a planilha foi salva.
